# riley-settings

The settings panel of the Riley desktop for Hyprland. C++ and Qt Quick. Every page, section and option is described
in an XML file, checked against an XML schema, so a new or changed setting is an edit to that file, not to the
panel's code. Your choices are kept in one XML file of their own, from which the panel writes each program's
configuration.

Work in progress: a rewrite of Riley's first settings panel.
